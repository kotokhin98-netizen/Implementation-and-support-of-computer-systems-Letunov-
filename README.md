1. Заголовочный файл libhelp.h
Этот файл нужен, чтобы главная программа знала, что существует функция gethelp.

#ifndef LIBHELP_H       // 1. Если макет LIBHELP_H еще не определен (защита от двойного включения)
#define LIBHELP_H       // 2. Определяем макет LIBHELP_H, чтобы пометить файл как обработанный

// 3. Объявляем функцию gethelp, которая будет находиться в библиотеке.
// 4. void означает, что функция ничего не возвращает.
// 5. const char *program_name — функция примет имя программы как текст.
void gethelp(const char *program_name); 

#endif                  // 6. Конец условия ifndef

2. Файл библиотеки libhelp.c
Здесь находится сама логика функции. Именно этот файл мы превратим в динамическую библиотеку.
c
#include <stdio.h>      // 1. Подключаем библиотеку для работы с выводом (printf)
#include "libhelp.h"    // 2. Подключаем наш заголовок, чтобы использовать функцию gethelp

// 3. Начинаем описание функции gethelp
void gethelp(const char *program_name) {
    
     4. Создаем первую временную переменную с описанием программы
    const char *description = "Моя учебная программа для демонстрации библиотек.";
    
    // 5. Создаем вторую временную переменную с версией и автором
    const char *version_info = "Версия 1.0 | Автор: Студент 2 курса";

    // 6. Выводим имя программы, которое передали из main
    printf("Справка для: %s\n", program_name);
    
    // 7. Выводим разделитель для красоты
    printf("--------------------------\n");
    
    // 8. Выводим описание из переменной
    printf("Описание: %s\n", description);
    
    // 9. Выводим версию из переменной
    printf("%s\n", version_info);
    
    // 10. Выводим разделитель
    printf("--------------------------\n");
    
    // 11. Подсказываем, как правильно запускать программу
    printf("Используй: %s --help\n", program_name);
}

3. Главный файл main.c
Это основная программа. Она проверяет, написал ли пользователь --help, и если да — обращается к библиотеке.
#include <stdio.h>      // 1. Нужно для printf
#include <string.h>     // 2. Нужно для strcmp (сравнение строк)
#include "libhelp.h"    // 3. Подключаем нашу библиотеку, чтобы видеть функцию gethelp

// 4. Главная функция программы
int main(int argc, char *argv[]) {
    
    // 5. Проверяем, есть ли второй аргумент (argc > 1)
    // 6. И сравниваем ли он равен "--help" (strcmp возвращает 0, если строки равны)
    if (argc > 1 && strcmp(argv[1], "--help") == 0) {
        
        // 7. Если условие верно, вызываем функцию из библиотеки
        // 8. Передаем ей имя программы (argv[0])
        gethelp(argv[0]);
        
        // 9. Завершаем программу успешно
        return 0;
    }

    // 10. Если флаг --help не введен, пишем обычное сообщение
    printf("Привет! Запусти меня с флагом --help\n");
    
    // 11. Завершаем программу
    return 0;
}

4. Как собрать (Команды в терминале)
Чтобы сделать библиотеку динамической, нужно использовать специальные флаги. Вводи эти команды по очереди в терминале (Linux):
# 1. Создаем объектный файл из кода библиотеки
# -fPIC нужен, чтобы код мог загружаться в любое место памяти (для динамических библиотек)
gcc -fPIC -c libhelp.c -o libhelp.o

# 2. Превращаем объектный файл в динамическую библиотеку (.so)
# -shared говорит компилятору сделать именно разделяемую библиотеку
gcc -shared -o libhelp.so libhelp.o

# 3. Собираем главную программу и линкуем её с нашей библиотекой
# -L. ищет библиотеки в текущей папке
# -lhelp подключает libhelp.so (префикс lib и расширение .so подставляются сами)
gcc main.c -L. -lhelp -o myprog

5. Как проверить (Задание про ldd)
Чтобы подтвердить, что библиотека действительно динамическая (а не вшита внутрь программы), используем команду ldd.
# 1. Запускаем программу с флагом, чтобы убедиться, что работает
./myprog --help

# 2. Проверяем зависимости программы
# Если увидишь строчку libhelp.so, значит сборка динамическая
ldd ./myprog
Что ты должен увидеть в ответе на ldd:
В списке строчек должна быть такая:
libhelp.so => ./libhelp.so (0x0000...)

Это значит, что программа не содержит код внутри себя, а подгружает его из файла libhelp.so при запуске.
6. Важный нюанс (Если программу не запускается)
Иногда Linux не видит библиотеку в текущей папке. Если при запуске ./myprog --help выйдет ошибка "library not found", напиши эту команду перед запуском:

# 1. Говорим системе искать библиотеки еще и в текущей папке
export LD_LIBRARY_PATH=.:$LD_LIBRARY_PATH

# 2. Теперь пробуем запустить снова
./myprog --help
